# Portofolio Mahasiswa Teknik

Template website portofolio berbahasa Indonesia dengan desain modern, profesional, minimalis, dan responsif. Dibangun menggunakan HTML, CSS, dan JavaScript tanpa framework atau proses build.

## Isi folder

- `index.html` — konten dan struktur halaman
- `style.css` — gaya visual dan responsif
- `script.js` — menu mobile, tahun otomatis, dan tombol kembali ke atas
- `assets/` — tempat menyimpan foto profil, sertifikat, atau gambar proyek milikmu

## Cara menyesuaikan

1. Buka `index.html`.
2. Ganti `[Nama Lengkap]` dengan nama kamu.
3. Perbarui deskripsi profil, latar pendidikan, keahlian, proyek, dan pengalaman.
4. Ganti `emailkamu@example.com`, tautan GitHub, dan LinkedIn dengan akun yang benar.
5. Pastikan klaim keterampilan dan hasil proyek sesuai dengan pengalaman nyata.
6. Jika menambahkan foto atau gambar, simpan di folder `assets/` lalu gunakan path relatif seperti `assets/foto-profil.jpg`.

## Publikasikan ke GitHub Pages

1. Buat repository GitHub. Untuk alamat `https://USERNAME.github.io`, nama repository harus persis `USERNAME.github.io` (ganti `USERNAME` dengan username GitHub kamu). Jika repository bernama `PORTOFOLIO`, alamat biasanya `https://USERNAME.github.io/PORTOFOLIO/`.
2. Unggah `index.html`, `style.css`, `script.js`, `README.md`, dan folder `assets/` ke root repository.
3. Pada repository, buka **Settings → Pages**.
4. Di **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu deployment selesai. Buka **Settings → Pages** dan klik tautan website yang ditampilkan.

## Catatan

- Repository `Public` paling mudah untuk publikasi GitHub Pages pada akun gratis.
- Perubahan bisa memerlukan beberapa menit untuk tampil.
- Template ini tidak memakai backend atau formulir kontak aktif. Tautan email menggunakan aplikasi email pengunjung.
- Font dari Google Fonts memerlukan koneksi internet; jika tidak tersedia, website menggunakan font sans-serif cadangan.
